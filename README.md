# C Programming Practice & Algorithms

A collection of introductory and intermediate C programs covering core syntax, control structures, loops, string processing, mathematical sequences, and pattern printing.

## Topics Covered

* **Conditionals & Input Handling:** Temperature classification, character case checks, and grade evaluation (`stdio.h`, `ctype.h`)
* **Loops & Sequences:** Sum of natural numbers (even/odd, squares), prime number checking, Fibonacci series, and factorials
* **Strings & Characters:** Vowel counting and character inspection
* **Nested Loops & Patterns:** Right-angled triangles, pyramids, hollow squares, Pascal's triangle, and spiral number matrices
